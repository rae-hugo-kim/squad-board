# E2E Checklist: 5단계 — 전술가 티어 · 공통 전술 · 오늘의 스쿼드

사람이 브라우저로 확인하는 체크리스트다. 자동화 버전은 `e2e/stage5.mjs`(`npm run e2e:stage5`, 1~4단계 뒤 같은 DB).

## Prerequisites

- [ ] 1~4단계 체크리스트의 전제(멤버 5명, Rae의 어센트 선호 오멘, 개인 전술 1건) 충족
- [ ] `npm run db:setup` 뒤 서버 실행. 시드가 전술가 3명(알파카·벵거·오르페브르)을 만들어 둔다

## Test cases

### 랜딩과 티어
**Given** 관리자로 입장
**When** 로그인
**Then** 첫 화면이 "오늘의 스쿼드"이고 본인이 참가자에 기본 체크되어 있다

- [ ] 관리 화면 역할 선택에 일반/전술가/관리자 세 가지가 있고, 시드 전술가 3명이 "전술가"로 보인다
- [ ] 멤버 한 명을 전술가로 바꾸면 적용 직후 선택 상자가 새 값으로 보인다(새로고침 없이)
- [ ] 전술가로 입장하면 네비에 `tactician`이 보이고 관리 메뉴는 없다

### 공통 전술과 권한
- [ ] 전술가·관리자의 새 전술 폼에만 "공통 전술" 체크와 우선도 입력이 있다(기본 해제). 일반 멤버에게는 없다
- [ ] 공통 전술로 만들면 보드 헤더와 목록에 "공통 · 우선 N" 배지, 목록에서 공통 전술이 우선도 순으로 맨 위
- [ ] 전술가는 다른 전술가의 공통 전술을 고칠 수 있지만 남의 개인 전술은 읽기 전용이다
- [ ] 일반 멤버는 공통 전술이 읽기 전용이고, 복제는 가능하며 복제본은 개인 전술이다
- [ ] 관리자는 모두 수정 가능. 전술 정보 폼에서 공통 여부·우선도를 바꿀 수 있다

### 오늘의 스쿼드 → 공통 전술 보드
**Given** 어센트에 공통 전술 2개 — 우선 1(전략가 2명 필요), 우선 2(전략가 1명)
**When** 랜딩에서 참가자 5명(전략가 선호는 Rae 1명)과 어센트를 고르고 "공통 전술 보드로"
**Then** 우선 1은 실행 불가로 건너뛰고 우선 2 보드가 열리며 "오늘의 라인업"에 슬롯 1 → Rae(오멘)이 보인다

- [ ] 보드의 슬롯 1 토큰 아래에 "Rae"가 표시된다
- [ ] "다른 공통 전술"에 우선 1이 취소선·"실행 불가" 툴팁으로 보이고, 클릭하면 그 보드에 "포기 권고" 배지와 빈 슬롯이 보인다
- [ ] "이 편성으로 세션 시작"은 같은 참가자·전술이 체크된 편성기로 간다. 편성기 카드의 전술 상자에도 "실행 불가 — 포기 권고"가 뜬다
- [ ] 공통 전술이 없는 맵을 고르면 안내 화면(편성 계산 링크)이, 참가자 없이 제출하면 랜딩에 안내 문구가 뜬다

## Edge cases
- [ ] 참가자 11명 이상이면 랜딩으로 되돌아오며 상한 안내
- [ ] 일반 멤버가 폼 값을 조작해 `isShared`를 보내도 서버가 거부한다(공통 전술은 전술가·관리자만)

## Known limitations
- 라인업은 조회 시점 계산이라 저장되지 않는다(세션 시작으로 기록)
- 전술가 시드 목록에 있는 멤버를 관리 화면에서 일반으로 내려도 다음 배포에서 다시 전술가가 된다(목록에서도 빼야 함)
