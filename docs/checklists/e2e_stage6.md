# E2E Checklist: 6단계 — 보드 조작 (배치 후 선택 복귀 · 스킬 크기 · 벽 · 자유 그리기 · 휠)

사람이 브라우저로 확인하는 체크리스트다. 자동화 버전은 `e2e/stage6.mjs`(`npm run e2e:stage6`, 1~5단계 뒤 같은 DB).

## Prerequisites

- [ ] 관리자(또는 작성자)로 입장해 아무 맵에서 새 전술을 만든다

## Test cases

### 배치 후 선택 모드
**Given** 팔레트에서 연막을 고른 상태
**When** 맵을 클릭
**Then** 연막이 놓이고 팔레트의 "선택 / 이동"이 켜지며, 보드 위 안내 칩이 "연막 선택됨"으로 바뀐다. 바로 끌어 옮길 수 있다

- [ ] Shift를 누른 채 클릭하면 같은 도구가 유지되어 연속 배치된다
- [ ] 경로(아군 이동 경로)는 더블클릭/Enter로 완성될 때 선택 모드로 돌아온다
- [ ] V = 선택, D = 자유 그리기, Esc = 취소·선택 해제

### 스킬 실제 크기와 핸들
- [ ] 요원 미지정 연막은 반경 "4.1 m", 바이퍼 Q(독구름)는 "4.5 m", 오멘 E는 "4.1 m"로 속성 패널에 미터로 표시된다
- [ ] 추정값 스킬(예: 몰리 3m)은 "기준 3m (추정)"으로 표시되고 "기준값" 버튼으로 되돌릴 수 있다
- [ ] 선택한 연막·몰리의 반경 핸들(원 오른쪽 점)을 끌면 반경이 바뀐다. 정보 스킬은 방향·범위 핸들
- [ ] 세이지 C(방벽 구슬)·바이퍼 E(독성 장막)·하버 E는 "벽 / 장막" 객체로 놓이고 길이 "10.0 m"(세이지) 등 기준 길이로 시작한다
- [ ] 벽의 양 끝 핸들을 끌면 반대쪽 끝은 고정된 채 길이·회전이 함께 바뀐다. 속성 패널의 길이(m)·회전(°) 슬라이더도 동작
- [ ] 벽 몸통을 끌면 이동한다

### 자유 그리기
- [ ] "자유 그리기"(D)를 고르고 색 견본을 고른 뒤 누른 채 끌면 선이 그려지고, 떼면 객체가 되며 선택 모드로 돌아온다
- [ ] 선택하면 속성 패널에서 색을 바꿀 수 있고, 선을 클릭해 선택·드래그 이동·Delete 삭제가 된다

### 휠 확대
- [ ] 보드 위에서 휠을 굴리면 커서 기준으로 확대·축소되고 페이지는 스크롤되지 않는다. 배율 버튼으로 초기화
- [ ] 보드 밖(팔레트·패널)에서는 평소처럼 스크롤된다

### 저장
- [ ] 저장 후 새로고침해도 벽(길이·회전)·자유 그리기(색·점)가 그대로다

## Edge cases
- [ ] 자유 그리기를 아주 짧게 클릭만 하면(점 1개) 객체가 생기지 않는다
- [ ] 맵 스케일이 동기화되지 않은 맵은 상단에 "맵 스케일 미동기화(기본값으로 크기 환산)" 안내가 뜬다

## Known limitations
- 스킬 크기 표의 "추정" 값은 공식 수치가 아니다 — 보드에서 맞추고, 확인되면 `src/lib/tactics/ability-geometry.ts`를 고친다
- 벽은 직선 1개로 그린다(하버 파도의 곡선은 표현하지 않는다)
- 터치(모바일) 조작은 미지원
