# E2E Checklist: 2단계 — 스쿼드 편성기 + 세션 기록

사람이 브라우저로 확인하는 체크리스트다. 자동화 버전은 `e2e/stage2.mjs`(`npm run e2e:stage2`).

## Prerequisites

- [ ] `npm run db:setup`으로 빈 DB를 만들고 `npm run dev` 실행
- [ ] 관리자로 입장해 멤버를 5명 이상 추가하고, 2명 이상이 어센트 선호를 저장

## Test cases

### 편성 계산
**Given** 활성 멤버 5명 이상, 일부가 어센트 선호 저장
**When** 스쿼드 편성에서 어센트와 참가자 5명을 고르고 "조합 계산"
**Then** 조합 카드 1개가 뜨고 선호가 있는 멤버는 1순위 요원, 없는 멤버는 "미입력" 경고

- [ ] URL에 `?map=ascent&m=...`가 남아 새로고침해도 결과가 유지된다
- [ ] 참가자 6명 이상이면 벤치가 다른 조합이 최대 3개 뜬다
- [ ] 참가자 4명이면 "빈 슬롯 1개" 경고가 뜬다
- [ ] Verify: 점수 = 1순위 3 / 2순위 2 / 3순위 1 + 자신감 보정(1→0, 3→1, 5→2)

### 수동 조정
- [ ] 요원 선택 상자를 바꾸면 "수동 조정됨"과 함께 점수·주의가 바로 바뀐다
- [ ] 이미 고른 요원은 다른 멤버 목록에서 비활성이다
- [ ] 선호 밖 요원을 고르면 그 멤버는 0점, "선호 밖"으로 표시된다

### 세션 시작과 경기 입력
**When** 날짜를 확인하고 "이 조합으로 세션 시작"
**Then** 세션 상세로 이동하고 1경기(어센트)에 멤버별 요원·포지션이 미리 채워져 있다

- [ ] 결과 없이 "확정" 버튼은 비활성이다
- [ ] 승/패/무, 스코어 13:9, 킬·데스를 넣고 "경기 저장" → "저장했습니다" → 새로고침 후 값 유지
- [ ] "확정" 후 배지가 붙고 관리자에게는 "확정 해제"가 보인다
- [ ] 경기 추가(바인드) → 2경기가 생기고 출전 멤버는 참가자 5명이 기본 선택

### 목록·통계
- [ ] 세션 기록 목록에 날짜·참가자 아바타·"2경기 확정 1"·"1승 1패"가 보인다
- [ ] 통계 맵별 표에 ASCENT·BIND, 멤버별 카드에 경기 수·승률·자주 쓴 요원·최근 경기가 보인다
- [ ] 결과 미입력 경기는 통계에서 빠진다

### 수동 세션·권한
- [ ] 세션 기록 우측 폼으로 날짜·참가자 2명·메모를 넣어 세션을 만들면 빈 상세가 뜬다
- [ ] 일반 멤버로 입장하면 확정 경기는 "확정된 경기입니다" 안내만 보이고 삭제·확정 해제·세션 삭제 버튼이 없다
- [ ] 일반 멤버도 미확정 경기는 저장할 수 있다

## Edge cases
- [ ] 참가자 11명을 고르면 계산하지 않고 상한 안내가 뜬다
- [ ] 같은 요원을 두 멤버에게 넣고 세션 시작 → 서버가 "같은 요원이 두 번" 오류를 돌려준다 (선택 상자가 막지만 직접 요청 시)
- [ ] 스코어를 한쪽만 넣고 저장 → "아군·적군을 함께 입력" 오류

## Known limitations
- 규칙(전략가 1·척후대 1)은 상수. 관리자 설정 화면 없음
- 조합별(같은 5명) 승률 조회 없음 — 데이터가 쌓인 뒤 추가
- 전술 슬롯 적합 점수(+2)와 사용 전술 연결은 3단계 이후
