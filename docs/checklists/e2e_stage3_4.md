# E2E Checklist: 3단계 전술 보드 + 4단계 유틸

사람이 브라우저로 확인하는 체크리스트다. 자동화 버전은 `e2e/stage3.mjs`, `e2e/stage4.mjs`.

## Prerequisites

- [ ] 1·2단계 체크리스트의 전제(멤버 5명, 어센트 선호 저장) 충족
- [ ] `npm run db:setup` 뒤 `npm run dev`, 관리자로 입장

## Test cases

### 전술 생성과 보드 편집
**Given** 전술 보드 메뉴에서 어센트
**When** 이름·진영·라운드·태그를 넣고 "전술 만들기"
**Then** 보드가 열리고 단계 1(셋업) 탭과 빈 슬롯 5개가 있다

- [ ] 팔레트에서 연막을 고르고 맵을 클릭하면 반투명 원이 생기고 우측에 속성(시전 요원·스킬·반경·링크)이 뜬다
- [ ] 요원 토큰(슬롯 번호·아군/적군), 섬광, 설치형, 몰리, 정보 스킬(부채꼴 각도·방향), 시전 위치(연결 핑 선택 → 점선 연결) 배치
- [ ] 아군 경로는 클릭마다 점이 찍히고 더블클릭/Enter로 완성, 끝에 화살촉. 상대 예상 동선은 점선
- [ ] 선택 도구로 객체를 드래그하면 이동, Delete 키로 삭제, "맨 위로"로 겹침 순서 변경
- [ ] 변경 뒤 2.5초쯤 지나면 "저장됨 HH:MM:SS", Ctrl+S도 저장. 새로고침해도 객체가 유지된다
- [ ] 휠로 커서 기준 확대, 스페이스+드래그로 이동, 배율 버튼으로 초기화

### 단계 · 슬롯 · 메타
- [ ] "+ 단계 추가"는 현재 단계를 복사해 "단계 2"를 만든다. 단계 이름·메모 저장, 마지막 단계는 삭제 불가
- [ ] 슬롯 1~5에 역할군/특정 요원/설명/포지션 힌트/고정 멤버를 넣고 "슬롯 저장"
- [ ] 전술 이름·진영·라운드·태그 수정 → 제목·배지 반영
- [ ] "PNG 저장"으로 현재 화면이 PNG로 내려받아진다

### 목록 · 복제 · 삭제 · 겹쳐보기 · 필터
- [ ] 목록에 진영·라운드·태그·작성자·구성(단계·객체·슬롯)이 보인다
- [ ] "복제"는 "(복제)" 이름의 새 전술을 내 것으로 만들고, 작성자/관리자만 "삭제"가 보인다
- [ ] 두 전술을 체크하고 "겹쳐보기" → 각 전술이 레이어 색으로 그려지고 투명도 슬라이더·단계 선택·레이어 토글이 동작
- [ ] 진영/라운드/태그 필터 링크로 목록이 좁혀진다
- [ ] 다른 멤버로 열면 "읽기 전용" 배지, 팔레트 비활성, 저장 버튼 없음, 복제는 가능

### 편성기 · 세션 연동
- [ ] 스쿼드 편성에서 전술을 체크하면 카드에 "전술 X 슬롯 n/m"과 바인딩(#1 → 멤버)이 뜨고 점수에 +2/슬롯(+1 포지션)이 더해진다
- [ ] 세션 시작 → 경기에 사용 전술이 체크되어 있고 "편성 바인딩" 문구가 보인다
- [ ] 경기 저장 시 사용 전술을 바꿀 수 있고, 통계의 "전술별" 표에 승률이 쌓인다

### 유틸
- [ ] 내 감도 저장 → eDPI와 360° 회전 거리(cm)가 보이고, 비교표에 전 멤버의 DPI·감도·eDPI·360°·크로스헤어 코드가 뜬다
- [ ] 크로스헤어 코드 저장 → 비교표 표시, "복사" 버튼으로 클립보드 복사
- [ ] 감도 찾기: "테스트 시작" → 포인터 잠금, 빨간 표적 8개 클릭(플릭) → 움직이는 표적 6초(트래킹) → 후보 B → 5라운드 뒤 추천 감도·eDPI·360° 표시 → "내 프로필에 저장"
- [ ] Esc로 잠금을 풀고 "중단"하면 대기 상태로 돌아온다
- [ ] 외부 유틸 카드 3개가 새 탭으로 열린다

## Edge cases
- [ ] 단계당 객체 300개, 경로 점 60개를 넘기면 더 추가되지 않는다
- [ ] 외부 링크에 URL이 아닌 문자열을 넣으면 저장이 거부된다
- [ ] 다른 맵의 전술 id를 경기에 넣으면 서버가 거부한다

## Known limitations
- 맵 탑뷰는 자리표시자 SVG (실제 이미지는 사용자가 교체)
- 요원 Veto의 스킬 명칭 미입력
- 시간축 애니메이션·댓글·공동 편집·다국어는 보류 (기획서 9절)
- 감도 찾기는 3D 투영이 없어 범위를 좁히는 용도
